# حوّلها — منصة الأدوات الرقمية العربية

نسخة أولى تعمل بالكامل داخل المتصفح: بلا حساب، بلا خادم، بلا قاعدة بيانات، بلا API خارجي أو تتبّع.

## التشغيل
افتح `index.html` مباشرة في المتصفح (أو شغّل `python3 -m http.server` داخل المجلد ثم افتح `http://localhost:8000`).

## الملفات
- `index.html`: بنية الصفحة والأدوات الخمس (كل أداة `<section class="tool">`).
- `style.css`: التصميم، الوضعان الفاتح والداكن، RTL، التجاوب.
- `script.js`: البحث والتصنيفات والإشعارات والنسخ والوضع الليلي ومنطق الأدوات.
- `qr.js`: مولّد QR محلي (مكتوب لهذا المشروع وفق ISO/IEC 18004، دون شيفرة طرف ثالث).
- `assets/favicon.svg`: الشعار.

## إضافة أداة جديدة
1. أضف `<section class="tool" id="tool-x" data-name="الاسم" data-desc="الوصف" data-cat="التصنيف" data-kw="كلمات بحث" data-icon="رمز">` في `index.html`.
2. اكتب منطقها في `script.js`. تظهر البطاقة وعنصر التنقل وتصنيفها وبحثها تلقائيًا.

## المكتبات والتراخيص
لا توجد مكتبات خارجية. `qr.js` شيفرة أصلية للمشروع. الخطوط هي خطوط النظام.

## الاختبارات (فعلية، في Chromium عبر Playwright وعلى `file://`، 34 من 34 نجحت)
- تحميل CSS وJS دون أخطاء؛ بحث موجود وغير موجود؛ التصنيفات.
- QR: خطأ عند الحقل الفارغ؛ تنزيل PNG وفك ترميزه بـ OpenCV أعاد النص العربي نفسه. كما فُكّت بنجاح 7 رموز بنسخ 1 و2 و4 و7 و10.
- النصوص العربية: تنظيف المسافات والأسطر الفارغة، العدّادات، الأحرف الكبيرة، المسح.
- الحاسبة: النسب والخصم والفاتورة والإكرامية، القسمة على صفر، الحقول الفارغة والقيم غير الصالحة، الأرقام العربية.
- الألوان: تطابق HEX وRGB والألوان المقترحة.
- كلمات المرور: أطوال 8 و20 و30 و64 بخيارات مختلفة، ورسالة عند عدم اختيار أي مجموعة، وعدم تخزينها.
- النسخ: النجاح ومعالجة رفض الإذن (محاكى برمجيًا).
- الوضع الليلي وحفظه بعد التحديث؛ عدم وجود تمرير أفقي بعرض 375px.

**لم تُنفَّذ:** مسح QR بكاميرا هاتف حقيقية؛ اختبار Safari وFirefox؛ اختبار قارئات الشاشة؛ اختبار على أجهزة فعلية. فحص إمكانية الوصول اقتصر على مراجعة الشيفرة (تسميات، تركيز، `aria-live`).

## القيود المعروفة
- Clipboard API تحتاج HTTPS أو localhost. عند `file://` أو رفض الإذن تُستخدم طريقة بديلة، وإن فشلت تظهر رسالة.
- QR: وضع البايتات وتصحيح أخطاء M ونسخ 1–20 (نحو 260 بايتًا؛ الحرف العربي بايتان). القناع ثابت (0) دون حساب العقوبات، وهو صالح للمسح لكن غير مُحسَّن.
- مؤشر قوة كلمة المرور تقديري ولا يضمن الحماية.

## خطوات مستقبلية
اختيار مستوى تصحيح أخطاء QR، اختيار القناع الأمثل، SVG للـ QR، مزيد من الأدوات، اختبارات آلية ضمن المشروع.
